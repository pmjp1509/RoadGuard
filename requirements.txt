# Computer vision
# ultralytics hard-depends on opencv-python, the GUI build, so that is what the image
# gets and the Dockerfile installs libgl1 for it. Pinning opencv-python-headless
# alongside it installed both: the GUI wheel won the shared `cv2` directory anyway and
# the pair cost 154 MB of duplicated shared libraries.
# The version is pinned because opencv-python 4.12 and later require numpy 2, which
# conflicts with the numpy pin below. Left unpinned, pip backtracks through every 4.12
# and later wheel before landing here, which makes the build slow and the result
# whatever pip happened to settle on.
